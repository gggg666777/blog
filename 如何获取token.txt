如何获取 GitHub token
========================

token 相当于一张「一次性密码」，让推送脚本能代表你上传代码。
整个过程大约 2 分钟。

第 1 步
-------
用浏览器打开这个网址：

    https://github.com/settings/tokens/new

（需要先登录 gggg666777 这个账号）


第 2 步
-------
页面上有几个格子，这样填：

  Note（备注）
      填：blog
      （随便写，只是给你自己看的）

  Expiration（有效期）
      选 90 days
      或者选 No expiration（永不过期，方便但安全性低一点）

  Select scopes（权限范围）
      只勾第一个大项：repo
      点一下 repo 这个词本身，它下面所有小项会自动勾上。
      其他的都不要勾。


第 3 步
-------
拉到页面最下面，点绿色的按钮：

    Generate token
    （生成令牌）


第 4 步
-------
页面顶部会出现一串字符，长这样：

    ghp_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

或这样：

    github_pat_xxxxxxxxxxxxxxxxxxxxxxxxxxxx

**这串字符只显示这一次，离开页面就再也看不到了。**

点它右边的复制按钮（两个方块叠在一起的图标）把它复制下来。

如果没复制成功就刷新或离开页面了，回到第 1 步重新生成一个即可。


第 5 步
-------
回到「推送到GitHub.cmd」，双击运行，
在提示 token: 的地方粘贴（在黑色窗口里点右键就能粘贴），按回车。


--------------------------------------------------------------------

安全提示
--------
这串 token 等同于你的账号密码（对这个仓库而言）。

  - 不要发给任何人，也不要发到聊天里
  - 不要提交到代码仓库
  - 它只保存在你电脑的 .git\config 文件里，不会上传

如果哪天觉得泄露了，去这个页面删掉它，token 就立刻失效了：

    https://github.com/settings/tokens
