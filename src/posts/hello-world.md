这是第一篇文章。它由 **Markdown** 写成，构建时渲染成 HTML。

## 这个博客是怎么搭的

没有数据库，也没有后端服务器，整套东西只有三块：

- **文章** = 仓库里的 `.md` 文件
- **渲染** = 构建时一次性生成静态 HTML
- **后台** = 一个静态页面，用 GitHub 账号登录后直接写文章

你写好文章点保存，它会往仓库提交一个 Markdown 文件，然后自动重新构建上线。整个过程通常一两分钟。

## 怎么写下一篇

两种方式随便挑：

1. 打开 [/admin/](/admin/)，在可视化编辑器里写，然后点 Publish。
2. 直接在仓库的 `src/posts/` 里新建一个 `.md` 文件。

代码块也能正常显示：

```js
console.log("hello, blog");
```

把这篇删掉，开始写你自己的内容吧。
